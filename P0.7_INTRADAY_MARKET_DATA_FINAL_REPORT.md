## Strategy V2 Hash Discrepancy

**Issue:** The current runtime hash `92ab27c...` differs from the documented `c39f1c...` hash.
**Analysis:** The parameters `BUY_THRESHOLD: 80`, `SELL_THRESHOLD: 45`, `ATR_MULTIPLIER: 2.0` remain absolutely identical mathematically. The divergence purely stems from Python `json.dumps()` serialization rules. The application explicitly uses `json.dumps(..., sort_keys=True)` which emits spaces around keys (`{"ATR_MULTIPLIER": 2.0, "BUY_THRESHOLD": 80.0, "SELL_THRESHOLD": 45.0}`). The earlier documented hash was likely generated from an integer-based struct or utilizing dense separators (`separators=(',', ':')`). The exact configuration object is functionally frozen.
