### 3.3 Price Series Consumer Separation Audit

The platform strictly isolates three distinct price concepts to prevent look-ahead and execution bias:

1. **Nominal Execution Prices (`open, high, low, close`)**:
   - Used exclusively by the paper trading engine and broker execution layer.
   - TrueData returns unadjusted nominal execution prices by default.
   - Cash dividends are **not** subtracted from nominal prices in the raw feed.
2. **Split/Bonus Adjusted Prices**:
   - Used for continuous chart plotting and technical indicator calculation (e.g. 50-day SMA, ATR).
   - Multiplicative split factors are computed independently via `PriceAdjustmentEngine`.
3. **Total Return Prices (Dividend Adjusted)**:
   - Used exclusively for performance evaluation, portfolio benchmarking, and Alpha factor modeling.
   - Isolated from nominal order execution.
4. **Demerger Tax-Cost Allocations**:
   - Stored in `tax_cost_allocation_pct` within `corporate_action_events`.
   - Invariant verified: Tax-cost allocations are **never** used as price adjustment factors.

## 4. Licensing, Provenance, and Authenticity Assessment

### 4.1 Cryptographic Distinction: Integrity vs. Authenticity

| Category | Definition | Proof Mechanism | Scope in HalalEquity |
| :--- | :--- | :--- | :--- |
| **Vendor Assertion** | Claims made in vendor API response or documentation. | Vendor JSON payload, HTTP status 200. | Ingestion candidate; subject to quarantine until validated. |
| **Artifact Byte Integrity** | Cryptographic proof that local file matches stored hash. | `SHA256(file_bytes) == recorded_sha256`. | Verified for all 23 local artifacts and all POC samples. |
| **Independently Verified Authenticity** | Legal and regulatory proof that issuing authority published the data. | Official NSE circulars, signed exchange notices, NCLT sanction orders. | Mandatory requirement for populating `corporate_action_events` and releasing quarantined bars. |

### 4.2 Licensing Terms & Research Eligibility

- **TrueData API License**: Permits non-redistributed internal algorithmic research, backtesting, and automated execution under the Developer / Individual Quant Tier.
- **Commercial Boundary**: Running in proof-of-concept / evaluation mode. Zero commercial fees incurred. Live commercial subscription requires user sign-off.
- **SEBI Regulatory Compliance**: TrueData is an authorized data vendor for NSE and BSE, avoiding the legal, IP, and WAF risks associated with scraping Yahoo Finance or retail portals.
