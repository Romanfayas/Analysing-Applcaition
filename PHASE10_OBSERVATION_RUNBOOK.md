# PHASE 10 OBSERVATION RUNBOOK

## Pre-Flight Check

1. **How to start PostgreSQL**
   ```bash
   docker compose up -d postgres
   ```
2. **How to verify database writable**
   ```bash
   docker compose exec postgres psql -U halal_user -d halal_equity -c "\dt"
   ```
3. **How to verify paper-only security**
   Check the environment variables provided to the running container:
   ```bash
   docker compose exec backend env | grep TRADING
   ```
   Must output: `PAPER_TRADING_ENABLED=true`, `LIVE_ORDER_EXECUTION=false`, `BROKER_TRADING_ENABLED=false`.
4. **How to verify Strategy V2 hash**
   ```bash
   docker compose exec quant python3 -c "import hashlib; print(hashlib.sha256(open('src/engines/backtest/engine.py','rb').read()).hexdigest())"
   ```
   (Document the output hash to ensure no parameter tuning occurred).
5. **How to start Go API and Python Engine**
   ```bash
   docker compose up -d backend worker quant
   ```
6. **How to verify health**
   Check the `/health` endpoint of the Go Backend.
   ```bash
   curl http://localhost:8080/health
   ```

## Active Session Monitoring

7. **How to start market observation**
   The observation naturally starts at 09:15 IST when the market opens, assuming the system is running.
8. **How to monitor the session**
   ```bash
   docker compose logs -f worker quant
   ```
   Look for `Market event received`, `Signal calculation completed`.
9. **How to verify PENDING orders (T Close)**
   At 15:30 IST, check PostgreSQL for pending orders:
   ```sql
   SELECT * FROM paper_orders WHERE status = 'PENDING';
   ```
10. **How to verify T+1 fills (T+1 Open)**
    Next day at 09:15 IST, check state transitions:
    ```sql
    SELECT * FROM paper_events WHERE event_type = 'ORDER_FILLED';
    ```

## End of Day (EOD) Operations

11. **How to verify database persistence**
    Ensure there are no Python memory-only states by inspecting the `paper_sessions` table.
12. **How to perform EOD reconciliation**
    Check the portfolio snapshots generated by the system at 15:30 IST:
    ```sql
    SELECT * FROM paper_portfolio_snapshots ORDER BY timestamp DESC LIMIT 1;
    ```
    Ensure `opening equity + realized P&L + unrealized P&L - transaction costs = closing equity`.
13. **How to stop safely**
    ```bash
    docker compose stop
    ```
14. **How to restart safely**
    ```bash
    docker compose start
    ```
    Verify no state loss in pending orders.
15. **Where to retrieve evidence**
    Extract logs: `docker compose logs > observation_evidence.log`
    Extract DB dump: `docker compose exec postgres pg_dump -U halal_user -d halal_equity > db_observation.sql`
