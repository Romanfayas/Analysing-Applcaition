### 3.2 Investigation: Why Multiple TCS Events Reference Artifact `NSE_CA_TCS_20261016_7b5b9325`

**Investigation**: An in-depth query into `corporate_action_source_artifacts WHERE id = 5` revealed:
1. `raw_payload` is a 3,606-byte JSON array containing multiple event objects returned by the exchange's corporate actions API for symbol `TCS`.
2. The payload contains items for:
   - Interim Dividend ₹10.00 (ex-date: 2024-10-18)
   - Interim Dividend ₹10.00 + Special Dividend ₹67.00 (ex-date: 2025-01-17)
   - Dividend ₹28.00 (ex-date: 2025-05-23)
   - Interim Dividend ₹10.00 (ex-date: 2025-07-16)
   - Interim Dividend ₹10.00 (ex-date: 2025-10-17)
   - Interim Dividend ₹10.00 + Special Dividend ₹58.00 (ex-date: 2026-01-16)
   - Dividend ₹30.00 (ex-date: 2026-05-22)
   - Interim Dividend ₹11.00 (ex-date: 2026-07-17)
   - Interim Dividend ₹12.00 (ex-date: 2026-10-16)
3. **Forensic Resolution**: Referencing the same artifact ID is **not** an error or data corruption. It reflects a normalized 1-to-many relationship where a single exchange response payload document (`EXCHANGE_API_JSON`) contains the entire chronological series of corporate action announcements for an equity. Each record in `corporate_action_events` represents one normalized corporate action extracted from this single parent document.

### 3.3 Limitation of `CONTROLLED_ARCHIVE` Provenance

1. Every source URL in `corporate_action_source_artifacts` begins with `CONTROLLED_ARCHIVE:`.
2. These artifacts represent local snapshot archives of earlier JSON API responses, having verified SHA-256 byte integrity.
3. However, direct HTTP requests to the upstream exchange endpoint (`https://www.nseindia.com/api/corporates-corporateActions`) encounter Akamai Bot Manager HTTP 403 Forbidden.
4. In strict adherence to project safety rules:
   - No WAF bypass scripts were deployed.
   - No proxy rotation was attempted.
   - No TLS fingerprint forgery was performed.
5. **Conclusion**: While internal byte integrity is 100% verified, **these local JSON archives cannot be treated as independently authenticated primary documents for releasing the remaining 23,132 quarantined bars or unlocking research**. Authoritative exchange circular PDFs from NSE Data & Analytics Ltd remain required for formal regulatory provenance.

## 5. Phase 5 — Shariah Evidence Remediation Status

### 5.1 Audit of the 31 `DATA_INSUFFICIENT` Securities

The 51 active equities partition into **0 PASS, 20 FAIL, and 31 DATA_INSUFFICIENT**:

1. **20 FAIL Securities**: Conventional commercial banks (`HDFCBANK`, `ICICIBANK`, `KOTAKBANK`, `SBIN`, `AXISBANK`), non-banking financial corporations (`BAJFINANCE`, `BAJAJFINSV`), insurance companies, and non-financial companies with debt ratios exceeding the 33.0% threshold.
2. **31 DATA_INSUFFICIENT Securities**: Operating industrial, IT, consumer, and pharma companies (`ADANIENT`, `ADANIPORTS`, `ASIANPAINT`, `BHARTIARTL`, `INFY`, `ITC`, `MARUTI`, `RELIANCE`, `TCS`, `WIPRO`, etc.).

### 5.2 Forensic Root Cause & Remediation Requirements

- **Cause**: Financial statements in the database (`financial_statements`) have `interest_income = NULL` across all 50 recorded companies because the automated `quoteSummary_v10` feed extracts top-level P&L summaries without itemized financial statement schedules.
- **Adopted Standard**: **AAOIFI Standard No. 21**:
  - Financial Ratio 1: $\text{Total Debt} / \text{Market Capitalization} < 33.0\%$.
  - Financial Ratio 2: $(\text{Cash} + \text{Interest-Bearing Securities}) / \text{Market Capitalization} < 33.0\%$.
  - Financial Ratio 3: $\text{Non-Operating Interest Income} / \text{Total Revenue} < 5.0\%$.
  - Business Activity: Prohibited business revenue $< 5.0\%$.
- **Fail-Closed Rule**: Under AAOIFI Standard No. 21, **missing financial values cannot be inferred as 0.0**. Any equity missing its statutory interest income schedule must be classified as `DATA_INSUFFICIENT`.
- **Trading Gating**: BUY orders for all 31 `DATA_INSUFFICIENT` equities are rejected by the compliance gate with HTTP 400:
  `"Shariah compliance gate blocked: cannot BUY <symbol> because screening status is DATA_INSUFFICIENT (must be certified PASS)"`.
- **Remediation Action Required**: Sourcing audited annual accounts and extracting Schedule/Note disclosures for "Other Income / Finance Income" (Interest on Fixed Deposits and Bank Deposits). **No synthetic values were inferred, and zero equities were promoted to PASS without primary evidence**.
